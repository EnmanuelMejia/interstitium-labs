# I18N — adding a locale

## Honesty

| Locale | Status |
|--------|--------|
| `en` | **Full** Learning OS chrome + key UI (founders / learn / prep / play / enroll CTAs) |
| `es` | **Full** (same surface as en) |
| `pt-BR`, `fr`, `de`, `zh-CN`, `ja`, `ko`, `hi`, `ar` | **Chrome / HUD scaffold** — nav, CTAs, HUD. Long-form English may remain; UI shows scaffold note + browser-translate hint |

Engine: `ILi18n` in `/assets/il-i18n.js` loads any `/i18n/{code}.json`. Completeness lives in `_meta.completeness` (`full` | `chrome`).

## Detection (privacy-first)

1. `localStorage` `il.lang` (picker)
2. `navigator.languages`
3. Soft geo: optional `window.IL_CF_COUNTRY` / `<meta name="cf-ipcountry">` + `Intl` timezone map
4. Fallback `en`

Geo **never** overrides a strong browser language (e.g. `en-US` in Mexico stays English).

## Add a locale

1. Copy `docs/i18n/en.json` → `docs/i18n/{code}.json`
2. Translate keys; set `_meta.locale`, `_meta.name`, `_meta.completeness`
3. Register in `docs/assets/il-i18n.js` → `LOCALES`
4. RTL (`ar`, …): ensure code is in the RTL map
5. Optional timezone / CF-IPCountry hints
6. Commit + push

## Markup

```html
<span data-i18n="nav.learn">Learn</span>
<input data-i18n-attr="placeholder:search.ph|aria-label:search.aria" />
<div data-il-lang-switcher></div>
```
