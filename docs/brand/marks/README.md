# Interstitium Labs — mark system

Two marks, one house.

| Mark | File(s) | Role |
|------|---------|------|
| **Canonical lockup** | `canonical-lockup.png` | **UI chrome** — header, footer, favicon family. Name + mark + motto. Never replace with the busy plate. |
| **IL Sigil OS** | `il-sigil-os.webp` / `.png`, `il-sigil-os-hero.webp`, `il-sigil-os-card.webp`, `il-sigil-os-512.png` | **Learning OS / campaign** — heroes, quest boards, OG (`/og-sigil.jpg`), ambient décor. Decorative; not a second nav logo. |

## Do

- Keep the lockup in product chrome.
- Use the sigil for motion (breathe / slow rotate), starfield heroes, and Learning OS surfaces.
- Respect `prefers-reduced-motion`: disable spin/particles; keep XP HUD.

## Don’t

- Don’t put the sigil in the sticky header as the primary logo.
- Don’t invent Stripe keys or monetization secrets in static docs.
