## Concept

Subnetting: the mask splits network from host, borrowing bits multiplies subnets, and each subnet loses two addresses — network and broadcast. Borrow bits, count subnets, subtract two.

## Voiceover cues

- `[0:04–0:10]` The mask: 1s are network, 0s are host
- `[0:10–0:16]` Borrow n bits → 2^n subnets
- `[0:16–0:22]` Each subnet loses 2 — network + broadcast
- `[0:22–0:26]` /26 = 62 hosts — the exam's favorite
