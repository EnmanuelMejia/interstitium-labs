Narrator: Narrator: Every process cycles through states — new, ready, running, waiting on I/O, and terminated — orchestrated by the scheduler.

Narrator: Narrator: The scheduler picks the next ready process, performs a context switch — saving registers, loading the new state — and dispatches it onto the CPU.

Narrator: Narrator: When a process blocks on I/O, it yields the CPU. The I/O completion interrupt wakes it back to ready — this is how one CPU serves hundreds of processes.
