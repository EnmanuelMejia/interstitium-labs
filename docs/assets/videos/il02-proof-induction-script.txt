Narrator: Narrator: Mathematical induction proves a statement for all natural numbers using just two steps — the base case and the inductive step — like toppling an infinite row of dominoes.

Narrator: Narrator: First, prove the statement for one — the base case. Then prove that whenever it holds for some k, it must hold for k plus one.

Narrator: Narrator: The base case topples the first domino; the inductive step guarantees each domino topples the next — so every statement P of n is proven.
