Narrator: Narrator: Each process sees a private virtual address space. The memory management unit translates virtual pages to physical frames through the page table.

Narrator: Narrator: The translation lookaside buffer caches recent mappings — a hit resolves in one cycle, a miss requires a full page-table walk.

Narrator: Narrator: Accessing an unmapped page triggers a page fault — the OS loads it from disk into a free frame and resumes the process. This is demand paging.
