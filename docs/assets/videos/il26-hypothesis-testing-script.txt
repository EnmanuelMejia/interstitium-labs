Narrator: Narrator: Hypothesis testing starts with a null — the default position of no effect. The data produces a test statistic; the question is whether it is extreme enough to reject the null.

Narrator: Narrator: The p-value is the probability of data this extreme if the null were true — not the probability the null is true. Small p means the data would be surprising under the null.

Narrator: Narrator: Rejecting a true null is a Type I error — a false alarm. Failing to reject a false null is Type II — a miss. Power analysis sizes the test to control both.
