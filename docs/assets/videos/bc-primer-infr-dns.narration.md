## Concept

A DNS lookup: the stub asks the recursive resolver, which walks root to TLD to authoritative, caching every answer. Recursive asks, authoritative answers — and TTLs set the freshness.

## Voiceover cues

- `[0:04–0:10]` Stub: your machine asks its resolver
- `[0:10–0:16]` Recursive: walks root → TLD → authoritative
- `[0:16–0:22]` Authoritative: the domain's own truth
- `[0:22–0:26]` Cache + TTL: speed with an expiry date
