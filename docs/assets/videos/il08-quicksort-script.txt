# Narration script: Quicksort Partitioning
# Style: 3b1b
# STATUS: Preview — narration coming (TTS blocked)

Narrator: Narrator: Quicksort picks a pivot, then partitions — every smaller element moves left, every larger moves right, and the pivot lands in its final position.

Narrator: Narrator: Then quicksort recurses on each side. The same partition logic applies to smaller and smaller subarrays until single elements remain.

Narrator: Narrator: On average, each level does linear work across log levels — O of n log n. A bad pivot every time degrades to quadratic — which is why pivot choice matters.
