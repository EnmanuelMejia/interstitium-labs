Narrator: Narrator: An unnormalized table repeats data — update one copy of a customer's address and miss another, and the database contradicts itself.

Narrator: Narrator: First normal form demands atomic values. Second removes partial dependencies on part of a key. Third removes transitive dependencies — every fact about the key, the whole key.

Narrator: Narrator: The normalized schema stores each fact once, linked by foreign keys. Queries reassemble the picture with joins — integrity at the cost of join complexity.
