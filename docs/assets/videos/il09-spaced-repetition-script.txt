Narrator: Narrator: Memory decays exponentially — the forgetting curve. Each successful recall resets the curve, and with spacing, it decays more slowly every time.

Narrator: Narrator: Spaced repetition schedules reviews at expanding intervals — one day, then three, then seven — always just before you would forget.

Narrator: Narrator: Rate each recall's difficulty and the algorithm adjusts — hard cards return sooner, easy cards later. The schedule adapts to your memory.
