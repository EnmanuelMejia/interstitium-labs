Narrator: Narrator: JavaScript's event loop continuously checks the call stack — when empty, it drains the microtask queue first, then takes one macrotask.

Narrator: Narrator: Promise callbacks are microtasks — they run to completion before the loop touches any macrotask, which is why promises beat setTimeout with zero delay.

Narrator: Narrator: A long synchronous task blocks the stack and starves the loop — the golden rule of async JavaScript is never block the event loop.
