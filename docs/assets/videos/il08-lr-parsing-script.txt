Narrator: Narrator: An LR parser reads input left to right. It shifts tokens onto a stack, consulting action tables built from the grammar.

Narrator: Narrator: When the stack top matches a grammar rule's right-hand side — a handle — the parser reduces it, popping the symbols and pushing the left-hand nonterminal.

Narrator: Narrator: Shift and reduce alternate until the stack holds just the start symbol and input is exhausted — the parse succeeds and the tree is implicitly built.
