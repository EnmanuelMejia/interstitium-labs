## Concept

An agent is an LLM in a while-loop: think, parse a tool call, run it, observe, append to memory — with guardrails bounding every action.

## Voiceover cues

- `[0:04–0:10]` Think: the LLM reasons about the goal
- `[0:10–0:16]` Act: it calls a tool — search, code, API
- `[0:16–0:22]` Observe: the result feeds back into memory
- `[0:22–0:26]` Loop until the goal checks out — then stop
