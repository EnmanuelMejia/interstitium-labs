Daily / weekly cadence (crush window)

Daily:  2h coding · 1h tool lab · 30m math
Weekend: ship one of the Phase 3 projects
Books: DevOps Handbook · Google SRE
Labs: hands-on lab platforms

Identity framing (use carefully)

I build and run systems as an engineer: code, pipelines, and platforms.
Portfolio labs (Interstitium, DevOps SuperLab) show how I learn in public —
they are inspectable products, not a claim of senior paid tenure.

Explain-back prompts (90 seconds)

  1. What is CIDR and why does /20 matter for a VNet plan?
  2. Explain Terraform state and why locking matters.
  3. Docker image layers — what invalidates the cache?
  4. How does Vault differ from secrets in env files?
  5. SLO vs alert?
  6. Blue/green vs rolling deploy tradeoff.
  7. First 15 minutes after a leaked cloud key.

Whiteboard scenarios

  • CI/CD for a service to Azure with prod approvals.
  • Users → WAF → app → managed DB; mark trust boundaries.
  • p99 doubled after deploy — first checks?
  • Snowflake VMs → Packer images + scale sets — sequence.
