Prep · Interview track

BNY Mellon–aimed DevOps interview prep

A structured 3-phase zero-knowledge → interview plan aimed at a Sr. Associate DevOps Engineer style JD (BNY Mellon). This is interview preparation and portfolio study — not an employment claim, affiliation, or offer.

3–6 month crush-interview framing: Phase 1 Math → Phase 2 Programming → Phase 3 DevOps tools + daily drills. Finish able to whiteboard systems, ship small automations, and talk Azure/IaC/CI like an engineer who owns operations — not “only an operator.”

3-phase syllabus SuperLab 12-mo mastery path Daily routine Enroll

Why this works

Banks hire people who can reason under load (math + networking), automate glue work (Python/Bash/Jenkins), and prove tool fluency with inspectable labs (Terraform, Ansible, Docker, Vault, Azure). This plan stacks those layers deliberately: no skipped foundations, every concept ends in a DevOps-shaped drill, and weekend projects become portfolio evidence you can open in an interview. Pair the intensive prep track with the longer 12-month DevSecOps mastery path if you want theory ↔ full-stack ↔ production ↔ security depth.

Key projects

  • Python · Azure VM restart — script that lists/restarts VMs via Azure API (or SDK), with dry-run + logging. Portfolio: GitHub README + sample output.
  • Terraform · HA web on Azure — VNet, LB, multi-VM / scale set, NSGs; remote state. Explain blast radius in interview.
  • Jenkins · test → Docker → Azure — Declarative pipeline: pytest gate → image build → push → deploy to Azure. Credentials via Jenkins IDs only.
  • Phase labs — disk-usage email alert; tar+cron backup; Ansible Apache on Linux; Dockerized Flask app; host Python project on GitHub with PRs.
