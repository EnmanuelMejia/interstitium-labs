Prep · Interview track

BNY Mellon–aimed DevOps interview prep

Intensive study path aimed at a Sr. Associate DevOps Engineer style JD (BNY Mellon). This is interview preparation — not an employment claim, affiliation, or offer. Start from zero math and zero programming; finish interview-ready for systems, cloud, and automation conversations.

Framing for interviews: you are becoming a versatile engineer focused on operations — not “only an operator.” Portfolio work (Interstitium Labs, DevOps SuperLab) demonstrates initiative; describe it as product/lab evidence, not paid production seniority.

How to use

  1. 01

    Math first

    If arithmetic feels shaky, stay in Math until CIDR, nines, and rates are fluent. Do the worked examples by hand.

  2. 02

    Then code

    Bash → Python → Groovy awareness. Automate small tasks. Read JSON. Call one API.

  3. 03

    Map the JD

    DevOps modules map every JD bullet. Finish with Drills: explain-back, whiteboard, RCA stories.
