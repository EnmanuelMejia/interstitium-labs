1. Bash essentials

The shell is how you talk to Linux. A script is a file of commands.

#!/usr/bin/env bash
set -euo pipefail   # exit on error; undefined vars fail; pipe fails propagate

NAME="interstitium"
echo "Hello, ${NAME}"

if [[ -f /etc/os-release ]]; then
  echo "Linux release file present"
fi

for f in *.log; do
  echo "found $f"
done

# Useful: pipelines
ps aux | grep nginx | awk '{print $2}'
  • variables — NAME=value, expand with $NAME or ${NAME}
  • exit codes — 0 success; non-zero failure ($?)
  • chmod +x script.sh then ./script.sh
  • Never paste secrets into scripts committed to git

2. Python essentials

# variables & types
count = 3
ratio = 0.95
name = "vault"
tags = ["prod", "east"]
meta = {"owner": "platform", "tier": 1}

# control flow
if count > 0:
    print("ok")
elif count == 0:
    print("empty")
else:
    print("negative?")

for t in tags:
    print(t.upper())

# functions
def needed_pods(rps, per_pod, util=0.7):
    import math
    return math.ceil(rps / (per_pod * util))

print(needed_pods(1200, 400))

# files
from pathlib import Path
text = Path("readme.txt").read_text()
Path("out.txt").write_text(text.lower())

Interview angle: explain why set -euo pipefail or Python exceptions matter in automation — fail loud, not silent.

3. JSON & HTTP APIs

import json, urllib.request

payload = {"service": "payments", "replicas": 3}
print(json.dumps(payload, indent=2))

# read JSON file
data = json.loads(Path("config.json").read_text())

# simple GET (stdlib)
with urllib.request.urlopen("https://httpbin.org/get") as resp:
    body = json.loads(resp.read().decode())
    print(body["url"])

In DevOps you parse Terraform outputs, Kubernetes manifests (YAML≈JSON), and webhook payloads constantly.

4. Groovy awareness (Jenkins)

You need to read Declarative Pipelines and know where to look — not become a Groovy expert on day one.

pipeline {
  agent any
  environment {
    APP = 'payments'
  }
  stages {
    stage('Test') {
      steps {
        sh 'pytest -q'
      }
    }
    stage('Build') {
      steps {
        sh 'docker build -t $APP:$GIT_COMMIT .'
      }
    }
  }
  post {
    failure {
      echo 'Notify on-call'
    }
  }
}
  • sh steps run Bash — your Bash skills transfer
  • Prefer Declarative over spaghetti Scripted until you must
  • Credentials: use Jenkins credentials IDs — never hardcode
