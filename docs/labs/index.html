Scenario · GitOps

Sync a broken Application

Argo CD shows OutOfSync. Trace desired vs live, then sync with respect for hooks.

  • Open Argo UI / CLI; note sync status
  • Diff manifests; identify drift source
  • Sync with prune only if intentional
kubectl get applications -n argocd
argocd app get <name> --grpc-web
argocd app sync <name> --grpc-web

Scenario · Policy

Gatekeeper denies a Pod

A deploy fails admission. Read the constraint message; fix the workload or the template.

  • kubectl describe / events for admission errors
  • Map message → ConstraintTemplate
  • Patch Pod security context; re-apply
kubectl get constrainttemplates
kubectl get k8spspprivilegedcontainer
kubectl apply -f apps/demo/ — watch deny

Scenario · CI

GHA fails on image build

Pipeline red on docker build. Separate registry auth from Dockerfile bugs.

  • Open Actions log; find first failing step
  • Reproduce locally with same tags
  • Fix layer or secret; re-run
gh run list --workflow=ci.yml
docker build -t demo:local .
# then push only with scoped creds

Scenario · Cluster

kind cluster cold start

From zero: bootstrap tools, bring cluster up, verify nodes Ready.

  • Install deps via make bootstrap
  • make kind-up && kubectl get nodes
  • Deploy sample via kustomize
make bootstrap
make kind-up
kubectl get nodes -o wide
