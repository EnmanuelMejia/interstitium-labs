Student quickstart

Clone → bootstrap → kind-up

Copy-friendly commands. Requires Docker, kind, kubectl, and Make. Optional: fish (some apply scripts), pre-commit, MkDocs.

1 · Clone

git clone https://github.com/EnmanuelMejia/devops-superlab.git
cd devops-superlab

2 · Tooling hooks

make bootstrap

3 · Local cluster

make kind-up

4 · Apply a documented env flow

make kustomize-dev
kubectl -n superlab-dev get deploy,svc,hpa

5 · Optional · GitOps + policy

make argocd-bootstrap
make gatekeeper-bootstrap

6 · Tear down

make kind-down

Full walkthrough lives in the repo’s docs/ (MkDocs). Host-local helpers (e.g. some fish scripts) are optional — documented make targets are the portable path.
