Learning tracks · By role

Pick a role. Follow the track.

hands-on role tracks: an ordered sequence of study guides per role — SysAdmin, DevOps, Cloud, SRE, Security, DBA, Full-Stack, Blockchain, Systems. Each stage expands into its full curriculum: objectives, concepts, labs, checkpoints. Exams are third-party; we teach the engineering.

All paths Noah Frontier catalog

Start from the job you want, not the course catalog. Each role below describes what practitioners actually do, names the Interstitium paths that prepare you, and lists the key skills hiring screens probe. These tracks are preparation — study guides, labs, and proof portfolios — not certifications and not employment promises.

Role track

Site Reliability Engineer

An SRE keeps production systems reliable at scale, blending software engineering with operations: defining service-level objectives, automating away repetitive toil, running incident response with structured postmortems, and trading shipping speed against reliability through error budgets.

Prepare with

Kubernetes SRE Path· Platform SRE Exceed· Linux Performance Spine

Key skills

  • Kubernetes troubleshooting under pressure
  • Linux performance diagnosis (CPU, memory, I/O)
  • SLO and error-budget reasoning
  • GitOps automation and policy gates
  • Incident response and postmortems

Role track

DevSecOps Engineer

A DevSecOps engineer builds delivery pipelines where security is a design input, not a final gate. They write infrastructure as code, wire policy checks into CI/CD, manage secrets and identities, and harden workloads before production — catching vulnerabilities in the pull request instead of the incident.

Prepare with

DevSecOps Mastery· IaC · Terraform · GitOps· SecOps Blue Team

Key skills

  • Reviewed Terraform modules and GitOps sync
  • Pipeline policy gates and shift-left checks
  • Secrets and identity management
  • Container and workload hardening
  • Security narratives for screens
Open DevSecOps Mastery →

Role track

Data Analyst

A data analyst turns raw operational data into decisions. They clean and join datasets, build analyses in notebooks with clear narrative, visualize findings for non-technical stakeholders, and defend their methodology — honest about what the data can and cannot support.

Prepare with

Data Analyst → ML· Ops Math · ALEKS Exceed· Data Science Cert Roadmap

Key skills

  • SQL: joins, aggregations, window functions
  • Notebook analysis with written narrative
  • Data visualization for stakeholders
  • Statistics and uncertainty literacy
  • Ops math: rates, percentages, distributions

Role track

Cloud Engineer

A cloud engineer designs, deploys, and operates workloads on cloud platforms. They reason about identity and networking boundaries, weigh cost against performance for every service choice, automate provisioning so environments are reproducible, and build observability that answers "what broke" before users notice.

Prepare with

AWS Cloud Ops Exceed· AWS Cloud Practitioner+· IaC · Terraform · GitOps

Key skills

  • IAM and VPC design fundamentals
  • Cost versus performance tradeoff analysis
  • Infrastructure as code provisioning
  • Observability: metrics, logs, traces
  • Cloud security and networking basics
Enter AWS Cloud Ops →

Role track

Security Analyst (Blue Team)

A blue-team analyst defends systems that are already running. They write and tune detections, triage alerts to separate signal from noise, harden configurations before attackers find them, and rehearse incident response in tabletop exercises — calm, precise, and documentation-first.

Prepare with

SecOps Blue Team· DevSecOps Mastery· Linux LF Essentials+

Key skills

  • Detection writing and alert triage
  • Log analysis across Linux and cloud sources
  • Workload and configuration hardening
  • Incident-response notes and tabletop narrative
  • Linux shell fluency for investigations
Join the Blue Team track →

Role track

Forward Deployed Engineer

An FDE works inside customer environments, where requirements are ambiguous and the network is never the one from the demo. They integrate products with real customer systems, debug across organizational boundaries, and ship working solutions under constraints they did not choose.

Prepare with

Forward Deployed Engineer· Full-stack desk map· Python for Systems

Key skills

  • Debugging in ambiguous, constrained environments
  • Customer-facing technical communication
  • Full-stack integration across system boundaries
  • Scripting for glue work and field fixes
  • Field documentation and handoff notes

Role track

AI / Machine Learning Engineer

An AI/ML engineer takes models from research into production. They understand how models are trained and where they fail, build retrieval and agent pipelines around them, and operate the GPU infrastructure underneath — with skepticism: measuring output quality and knowing when a simpler non-AI solution wins.

Prepare with

NVIDIA AI Course Track· Data Analyst → ML· Python for Systems

Key skills

  • LLM and RAG pipeline concepts
  • Model evaluation and failure-mode skepticism
  • GPU and AI infrastructure literacy
  • Python glue services with tests
  • Data workflows feeding model systems

Role track

Linux Systems Engineer

A Linux systems engineer owns the foundation everything else runs on. They administer servers from the shell, automate repetitive work with scripts, diagnose CPU, memory, and I/O problems under pressure, and keep systems patched and reproducible.

Prepare with

Linux LF Essentials+· Linux Performance Spine· DevOps Zero → Hire

Key skills

  • Shell fluency and bash automation
  • Performance diagnosis from the command line
  • System hardening and patching discipline
  • Methodical troubleshooting under pressure
  • Reproducible, scripted system builds
