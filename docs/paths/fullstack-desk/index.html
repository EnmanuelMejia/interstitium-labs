Zero → interview outline (12–16 weeks)

Aggressive self-paced map. Adjust calendar; keep evidence public on GitHub.

  1. Weeks 1–2 · Web foundations — HTML/CSS layout, JS/TS fundamentals, Git branching, JSON.
  2. Weeks 3–5 · Backend lane A (Java + Spring Boot) — REST CRUD, validation, tests, OpenAPI stub.
  3. Weeks 6–8 · Frontend (Angular) — components, routing, HTTP client, forms; consume your API.
  4. Weeks 9–10 · NodeJS secondary — small BFF or webhook worker; compare with Spring mentally for interviews.
  5. Weeks 11–12 · C# exposure — ASP.NET minimal API or console + xUnit; enough to read C# in a mixed shop.
  6. Weeks 13–14 · Docker + SDLC artifacts — containerize stack; BRD/SRD + test plan + demo script.
  7. Weeks 15–16 · Interview loops — system design light (N-tier, auth, caching), behavioral STAR, honest elevator (Tell me about yourself).

Stack lanes (do not boil the ocean)

  • Primary: Java + Spring Boot + Angular + Docker + PostgreSQL.
  • Secondary: NodeJS for JSON APIs / tooling.
  • Tertiary: C# literacy (read + small service), not dual mastery.
  • Skip cloning Azure/Jenkins DevOps crush from /prep/devops/ — mention Docker only as app packaging.

Three portfolio projects (evidence)

  1. Eagle-lite CRUD — Angular UI + Spring API + Postgres; Docker Compose; README with BRD one-pager.
  2. JSON integration worker — Node service that validates payloads, retries idempotently, writes audit log.
  3. Ops→app bridge — small inventory and ticketing UI, labeled portfolio, not “I built Eagle.”

Interview framing

  • Open with the honest IT→engineering bridge, then show repos — never invent VP tenure.
  • If pressed on 7–9 years SWE: acknowledge gap; emphasize transferable ops scale, supervision, and accelerating full-stack evidence.
  • Separate from DevOps Sr. Associate narrative — different JD, different stories.
