Zero → interview outline (12–16 weeks)

Aggressive self-paced map. Adjust calendar; keep evidence public on GitHub.

  1. Weeks 1–2 · Web foundations — HTML/CSS layout, JS/TS fundamentals, Git branching, JSON.
  2. Weeks 3–5 · Backend lane A (Java + Spring Boot) — REST CRUD, validation, tests, OpenAPI stub.
  3. Weeks 6–8 · Frontend (Angular) — components, routing, HTTP client, forms; consume your API.
  4. Weeks 9–10 · NodeJS secondary — small BFF or webhook worker; compare with Spring mentally for interviews.
  5. Weeks 11–12 · C# exposure — ASP.NET minimal API or console + xUnit; enough to read C# in a mixed shop.
  6. Weeks 13–14 · Docker + SDLC artifacts — containerize stack; BRD/SRD + test plan + demo script.
  7. Weeks 15–16 · Interview loops — system design light (N-tier, auth, caching), behavioral STAR, honest elevator (Tell me about yourself).

Stack lanes (do not boil the ocean)

  • Primary: Java + Spring Boot + Angular + Docker + PostgreSQL.
  • Secondary: NodeJS for JSON APIs / tooling.
  • Tertiary: C# literacy (read + small service), not dual mastery.
  • Skip cloning Azure/Jenkins DevOps crush from /prep/devops/ — mention Docker only as app packaging.

Three portfolio projects (evidence)

  1. Eagle-lite CRUD — Angular UI + Spring API + Postgres; Docker Compose; README with BRD one-pager.
  2. JSON integration worker — Node service that validates payloads, retries idempotently, writes audit log.
  3. Ops→app bridge — small inventory and ticketing UI, labeled portfolio, not “I built Eagle.”

Interview framing

  • Open with the honest IT→engineering bridge, then show repos — never invent VP tenure.
  • If pressed on 7–9 years SWE: acknowledge gap; emphasize transferable ops scale, supervision, and accelerating full-stack evidence.
  • Separate from DevOps Sr. Associate narrative — different JD, different stories.

Concept glossary

The words this desk map uses

  • JD map — the keyword map of real job descriptions against the study outline: which terms employers actually use, mapped to the lanes that teach them.
  • Stack lane — one of the three study lanes: primary (Java + Spring Boot + Angular + Docker + PostgreSQL), secondary (NodeJS for JSON APIs), tertiary (C# literacy — read and small service, not dual mastery).
  • BRD / SRD — business and software requirements documents: the mini-BR D + test plan you write for each portfolio project, mapping requirements hygiene from process work into engineering.
  • BFF — backend-for-frontend: the small Node service pattern in the weeks 9–10 lane, compared mentally with Spring for interviews.
  • N-tier — the system-design-light shape for interview loops (UI → API → data), with auth and caching as the follow-up questions.
  • STAR — the behavioral answer shape (Situation, Task, Action, Result) used to frame portfolio stories — scoped to what you actually built, no borrowed war stories.
  • RACI — the team-coordination shorthand for the desk's teamwork signals: who is responsible, accountable, consulted, informed — lead with facilitation.
  • Prep only — this page's honesty boundary: a study map, not a job claim; the public record is the work you produce, labeled portfolio.

Worked procedure

Ship one portfolio project, start to finish

  1. Pick the lane. Choose the project's stack lane — Java + Spring Boot for the backend-heavy build, Angular for the frontend, Node for the integration worker.
  2. Write the mini-BR D. One page: what the app does, the data it touches, the test plan. This is the requirements-hygiene artifact interviewers read first.
  3. Build the API. REST CRUD with validation, tests, and an OpenAPI stub; weekly katas if the language is a rebuild-from-zero.
  4. Wire the UI. Consume your own API (Angular components, routing, HTTP client, forms) — the integration is the interview story.
  5. Containerize. Multi-stage image, Compose for local API+DB — Docker as app packaging, not a re-syllabus of DevOps.
  6. Write the README and demo script. README with the BRD one-pager, demo script for the interview loop, STAR stories scoped to what you built.

Project brief

The three-project evidence brief

Deliverable: the page's three portfolio projects — an Eagle-lite CRUD (Angular UI + Spring API + Postgres, Docker Compose, README with BRD one-pager), a JSON integration worker (Node service that validates payloads, retries idempotently, writes an audit log), and an ops→app bridge UI — each labeled portfolio, never "I built Eagle."

Acceptance: all three run from a fresh clone; you can open with the honest IT→engineering bridge, show the repos, and answer the 7–9-years question with the gap acknowledged and the accelerating evidence on screen.
