Forward Deployed Engineer — role loop

Own the field loop: discover → scope → integrate → evaluate → deploy → adopt → handoff → productize. Distinct from pure SWE (feature factory) and from bank DevOps interview crush.

  1. Customer discovery & success metrics (smallest slice that proves value).
  2. Technical decomposition & SoW / RACI.
  3. Integration patterns — webhooks, idempotency, retries, legacy plumbing.
  4. Evals & reliability gates before “demo day.”
  5. Customer-env deploy, rollback, dual-run, security review.
  6. Adoption / ROI narrative + reusable field→core pattern.

Field simulations & labs

  • Vague customer discovery · broken APIs · contradictory data
  • Hallucinating RAG · enterprise security review · production incidents
  • Architecture tradeoffs · board-level demonstration
  • Terminal-style diagnostics: logs, SQL, eval gates, rollback
  • Architecture laboratory: data, integrations, models, eval systems

Capstone ten-gate contract

1 Discovery evidence
2 SoW
3 Architecture + threat model
4 Working vertical slice
5 Eval suite
6 Production plan
7 SLO / runbook
8 Adoption / ROI
9 Executive defense
10 Reusable field pattern (field → core)

Graduate claim: not only “I built something,” but “I found something repeatable in the field and converted it into organizational leverage.”

Evidence vault (exportables)

Discovery Brief, Workflow/RACI maps, SoW, ADR, threat model, eval plan/report, data contracts, SLOs, runbooks, postmortems, cost/ROI briefs, adoption plans, handovers, field-to-core memos, executive outcome notes.
