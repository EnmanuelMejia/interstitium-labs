    FAQ

    Frequently asked questions

    • What is shared responsibility for S3 public access?
      AWS secures the S3 service; you secure your bucket policy. A public bucket is almost always a customer-side misconfiguration — the path's side-quest walks you through drawing the boundary for a static site plus API.
    • Can I prove AWS concepts without a paid account?
      Yes — that is the local-proof phase: docker-compose stand-ins, billing-alarm narratives, and CloudWatch-lite concepts. Some CLF domains genuinely need the real console; those are labeled optional, honestly.
    • When is on-prem still rational?
      When data gravity, compliance, or steady-state cost beats the cloud's elasticity premium. The cloud-fluency phase teaches the tradeoff, not the slogan — “cloud first” is a strategy, not a law of physics.
    • Public subnet vs private subnet — how do I think about it?
      Draw it: public subnets route to an internet gateway; private subnets route through NAT. The side-quest has you draw the diagram because interviewers ask for the picture, not the paragraph.
    • Does this grant the CLF-C02 certification?
      No. This is CLF-C02-shaped readiness — the concepts, tradeoffs, and interview surface. The exam and its credential stay with AWS.
    • How long does it take?
      Self-paced across four phases: cloud fluency, core services map, local proof, then exam and interview surface. The gate is demonstration, not a calendar.
