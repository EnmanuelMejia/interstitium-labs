Part 1A · BU MET undergraduate CS certificate (reconstructed)

CS-101

Intro Programming & Computational Thinking

Algorithms, types, control flow, functions, OOP intro; Python primary + Java intro; CLI labs.

CS-201

Data Structures & Algorithms

Arrays, lists, stacks, queues, hash tables, trees, graphs, Big O, sort/search, recursion; implement from scratch; LeetCode.

CS-301

Computer Systems & Architecture

Memory hierarchy, CPU, assembly basics, OS processes/threads/scheduling/VM; C pointer labs. Revisit in Months 10–12 for security depth.

CS-401

OOP Design & Software Engineering

Inheritance, polymorphism, patterns, UML, Agile/Waterfall, Git; larger app (e.g. library system) in Java/C++ on GitHub.

Part 1B · NSCC Full Stack Software Development (reconstructed)

DEV-101

Front-End Fundamentals

HTML5, CSS3, JS ES6+, responsive, a11y; static portfolios.

DEV-102

Advanced Front-End

React or Vue, state, components, APIs; SPA lab.

DEV-201

Back-End

Node/Express or Python Django/Flask, REST, DB, OAuth/JWT; todo/blog API.

DEV-202

Databases

SQL Postgres/MySQL, normalization, ACID; MongoDB intro; schema + complex queries.

DEV-301

Full Stack Integration & Deployment

FE+BE, Docker, basic CI/CD, cloud deploy; capstone fully deployed containerized app.

Part 2 · 12-month schedule

Months 1–3

Foundation & Azure core

BU CS-101 + CS-301 · NSCC DEV-101 + DEV-202 · KodeKloud Linux/Git/Shell · Cert AZ-104.

Weekly capstone: static site + Postgres form + Azure VM + NSG harden.

Months 4–6

Application & DevOps pipeline

BU CS-201 · NSCC DEV-102 + DEV-201 · KodeKloud Docker/K8s fundamentals/Jenkins · Cert AZ-400.

Weekly capstone: containerize React+Node, Jenkins→Docker→minikube, ACR.

Months 7–9

Orchestration & security shift

BU CS-401 · NSCC DEV-301 · KodeKloud K8s advanced/Terraform/Ansible · Cert CKA.

Weekly: Terraform AKS, Helm deploy, Ansible bastion.

Months 10–12

Sec in DevSecOps

Deepen CS-301 for security · refactor capstone · KodeKloud security scanning/Vault/monitoring · Cert CKS.

Final portfolio: Terraform AKS + Azure DB + Key Vault; containerized app; Jenkinsfile with SAST (Snyk)/Trivy/staging/tests/approval/prod; non-root, network policies, secrets in Key Vault.

Sample week (Month 2)

  • Mon — hash tables (CS-201 warm-up)
  • Tue — React + API (DEV-102)

  • Fri — Terraform → ACI + README
