Paths · Certification

Gold-standard certification roadmap for aspiring data scientists (2025)

Audience: beginner data analyst → data scientist. Sequence: foundational skills → tool mastery → advanced analytics / ML → leadership credentials. 2025 guidance only — prices, hours, and product names change; confirm on provider sites before buying.

Phase 1 · Foundational data analytics

Google / MOOC platforms

Google Data Analytics Professional Certificate

Focus: spreadsheets, SQL, R, Tableau, ethics, storytelling.

Duration: ~6 months @ ~10 hrs/week · Cost: ~$39/mo (a MOOC platform).

Why: true beginner on-ramp with a capstone portfolio piece.

IBM / MOOC platforms

IBM Data Analyst Professional Certificate

Focus: Python, Excel, SQL, Cognos.

Duration: ~11 months · Cost: ~$39/mo.

Why: complements Google with stronger Python + cloud-flavored tools.

Phase 2 · Tools & advanced analytics

Microsoft

Power BI Data Analyst Associate

Power BI, DAX, modeling, viz · 100–120 hrs · ~$165 exam · BI insights fluency.

Tableau

Desktop Specialist / Associate

Dashboards & interactive reporting · 30–35 hrs · $100–$250 · storytelling craft.

CompTIA

Data+

Mining, governance, basic stats · 1–2 months · ~$253 · vendor-neutral literacy bridge.

Phase 3 · Transition to data science

IBM / MOOC platforms

IBM Data Science Professional Certificate

Python, ML, APIs, predictive modeling · ~140 hrs · ~$39/mo · Jupyter + ML pipelines.

SAS

Certified Advanced Analytics Professional

Predictive modeling, ML, big data · 3–6 months · ~$1,800 · enterprise stats weight.

AWS

AWS Certified Data Analytics

Lakes, Redshift/Glue, cloud analytics · 2–3 months · ~$300 exam · modern cloud DS.

Phase 4 · Leadership credentials

INFORMS

Certified Analytics Professional (CAP)

Full lifecycle, ethics, deployment · self-paced · ~$695 · senior strategic signal.

Harvard Extension

Harvard Data Science Certificate

ML, statistical modeling, big data · 1–2 years · cost varies · prestige / rigor.

Roadmap tips

  • Portfolio — ship every capstone to GitHub/Notion; prefer evidence over badge screenshots.
  • Networking — Microsoft Learn community, INFORMS local/virtual events.
  • Continuous learning — Kaggle practice, keep an AI-upskilling loop without abandoning statistics foundations.

FAQ

Frequently asked questions

  • Where does a true beginner start?
    The Google Data Analytics Professional Certificate: spreadsheets, SQL, R, Tableau, ethics, and storytelling in about six months at ten hours a week, with a capstone portfolio piece. It is the on-ramp the roadmap opens with.
  • What do these certificates cost?
    Priced at the time the roadmap was written — for example about $39/month on a MOOC platform for the Google certificate. Prices change; confirm current pricing on the vendor's page before budgeting.
  • Do I need all ten credentials?
    No. The roadmap is ordered by lane: the analyst lane (Google, IBM Data Analyst, Power BI, Tableau) versus the data-science lane (IBM Data Science, CAAP, AWS Data Analytics, CAP, Harvard). Pick the lane that matches the jobs you want.
  • Does Interstitium Labs confer any of these?
    No. This is an independent roadmap to third-party credentials; the certificates come from Google, IBM, Microsoft, CompTIA, AWS, and the other issuers. Our sequences (SQL, math-for-ML, databases, local AI lab) are the preparation layer.
  • How do I prepare for the technical parts here?
    The module-to-lesson map anchors each area to a Learn sequence: Core SQL Engineering, Math for ML, Database Admin, and the Local AI Lab. Preparation is original practice material, not reproduced exam content.
  • Why is a Harvard certificate on a data roadmap?
    As a certificate program (not a degree) in the advanced tier. Offerings change — verify the current program on Harvard's site before planning around it.

Concept glossary

The words this roadmap uses

  • Data analyst lane — the roadmap's first two phases: Google and IBM Data Analyst certificates plus Power BI, Tableau, and CompTIA Data+ — the tools lane that precedes data science.
  • Data-science lane — phases 3–4: IBM Data Science, SAS Certified Advanced Analytics Professional, AWS Certified Data Analytics, CAP, and the Harvard Data Science Certificate — the transition and leadership tiers.
  • DAX — the formula language for Power BI modeling and measures; part of the Power BI Data Analyst Associate skill set.
  • Vendor-neutral literacy — what CompTIA Data+ is used for here: mining, governance, and basic stats without tying you to one vendor's stack.
  • CAP — the INFORMS Certified Analytics Professional: full lifecycle, ethics, and deployment — the senior strategic signal in phase 4.
  • Capstone portfolio piece — the beginner on-ramp's deliverable (e.g. the Google certificate's capstone): shipped to GitHub or Notion, preferred over badge screenshots as evidence.
  • 2025 guidance — this page's stated vintage: prices, hours, and product names change; confirm on provider sites before buying.

Worked procedure

Run the roadmap without buying the wrong thing

  1. Pick your lane. Decide analyst lane vs data-science lane first — the roadmap is ordered by lane, and you do not need all ten credentials.
  2. Start with the on-ramp. The Google Data Analytics Professional Certificate (~6 months at ~10 hrs/week) or the IBM Data Analyst certificate, depending on whether you want stronger Python and cloud-flavored tools.
  3. Verify price and scope before paying. Confirm current pricing, hours, and exam names on each provider's site — this page is 2025 guidance and catalogs change.
  4. Ship every capstone to GitHub. Prefer evidence over badge screenshots: notebooks with written narrative, dashboards, and the portfolio piece each credential's capstone produces.
  5. Prepare the technical parts here. Use the lesson map (Core SQL Engineering, Math for ML, Database Admin, Local AI Lab) as the preparation layer — original practice, not reproduced exam content.
  6. Keep the loop open. Kaggle practice and an AI-upskilling loop, without abandoning statistics foundations — the roadmap's continuous-learning tip.

Project brief

The evidence brief for this roadmap

Deliverable: a public portfolio that outlasts the badges — narrative notebooks with written methodology, dashboards with stakeholder-facing storytelling, and one end-to-end analysis (data → model → deployed insight) that defends its methodology honestly about what the data can and cannot support.

Acceptance: a hiring analyst can reproduce your analysis from the repo and follow your narrative. Certificates come from Google, IBM, Microsoft, CompTIA, AWS, and the other issuers — Interstitium confers none of them; our sequences are the preparation layer.
