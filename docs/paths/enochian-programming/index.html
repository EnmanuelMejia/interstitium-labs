Critical principles

  • Clearly label primary evidence, scholarly inference, later tradition, and personal belief.
  • Teach manuscript provenance, transcription, paleography, citation, and uncertainty.
  • Respect religious and spiritual interpretations while preserving source criticism.
  • Distinguish Dee-era documentary evidence from Golden Dawn / Crowley / modern reconstruction.

Programming + Hermetica bridge

Use programming as a philological instrument, not as “casting.” Suggested stack for Interstitium builders:

  • Python for corpus cleaning, TEI-lite XML, SQLite/Postgres provenance tables.
  • TypeScript + static site for manuscript viewers and lexicon UIs.
  • Git as editorial history; PRs as peer review proxies.
  • Optional: graph DB / JSON-LD for reception-history edges — always cite.

Shared math → engineering spine

Import also sketched numeracy→CS phases. Cross-link Prep math rather than duplicating a desk crush content:

  2. Linear algebra & probability (for modeling, not mysticism)
  3. Data structures & algorithms → systems literacy
