Update enrollment links

  1. Create Stripe Payment Links (and optional PayPal buttons) — see payments.md.
  2. Paste URLs into docs/enroll/config.js; set each tier’s stripeEnabled / paypalEnabled and top-level paymentsLive: true.
  3. Commit + push main; confirm CF deploy; open /enroll/ and test one live link.

Go-live checklist (Stripe / PayPal)

  • ☐ Stripe account activated for live mode
  • ☐ Three Payment Links created (Prep Sprint, DevSecOps Mastery, Full Academy)
  • ☐ Success URL → https://interstitiumlabs.dev/enroll/success.html; cancel → …/cancel.html
  • ☐ Optional PayPal no-code payment links for the same three products
  • ☐ Placeholders replaced in config.js; no secret keys in repo
  • ☐ Manual email kickoff process until webhooks (phase 2)
