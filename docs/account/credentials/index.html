Secure store

Save a login securely

This is the one place a password is ever typed on this platform. It travels over HTTPS straight into the encrypted secure store. Noah and Genesis can then use the login through the store — they see that it exists and when it was saved, never the password itself. You never paste a password in chat.

Service login

For job sites, Proton Pass is the recommended store of record — use the second button and Noah will point you to the vault when a task needs that login. Every save, use, and removal is written to your account’s security log (service name and time only — never the password).
