Lawrence Public Schools
Enrollment Analysis

An interview data exercise analyzing five years of Lawrence Public Schools enrollment (2019–2024) from Massachusetts DESE public profiles — built with Python, pandas, and matplotlib, and presented to school commissioners, HR leadership, and district stakeholders. Prepared for an HRIS & Data Analyst role, April 2025.

What was built

  • End-to-end Python data pipeline: ingestion and cleaning of five years of Massachusetts DESE district profile exports with pandas.
  • Enrollment-trend modeling with year-over-year change analysis, visualized with matplotlib for a non-technical leadership audience.
  • Demographic segmentation — race/ethnicity, English-learner status by grade band, and special-population overlays.
  • Executive-ready findings deck translating statistical results into staffing and funding decisions.

Recommendations delivered

  • Bilingual hiring strategy aligned to the 48.1% ELL kindergarten cohort.
  • Title I funding alignment recommendations tied to quantified demographic shifts.
  • Real-time enrollment dashboard proposal so leadership stops relying on annual static snapshots.

Stack

Python · pandas · matplotlib · Massachusetts DESE public data · data storytelling for executives
