Selected project · September–October 2026

Sovereign hybrid AI for manufacturing.

Independent enterprise architecture research and executive presentation by Enmanuel D. Mejia, founder of Interstitium Labs. Prepared for a SunDance USA candidate meeting, this design explores private AI, safely routed frontier models and human-governed automation for commercial print and packaging operations.

Project status: 37-page AI Implementation UltraPlan and 17-slide executive vision deck completed. The infrastructure, integrations, pilots and agents described below were proposed, not deployed at SunDance. This was independent candidate research, not paid consulting or employment.

Proposed architecture

The sovereign hybrid AI fabric.

Requests enter a classification and model-routing gateway that considers sensitivity, task type, cost and latency. Unknown or sensitive data fails closed to local handling.

Tier 1 · Private inference

On-premises, open-weight models on segmented GPU infrastructure for client artwork, MIS data, job tickets, color profiles and internal production records.

Tier 2 · Frontier reasoning

Authorized model APIs for sanitized reasoning, script drafting and troubleshooting, governed by explicit transmission and cost policies.

Decision-layer pilot

Evaluate TypeSafe Jev for structured triage/scoring with measurable calibration, human escalation and a local classifier fallback. Proposed, not deployed.

Operating principle: LLMs generate, the evaluated decision model scores, deterministic software governs, and humans approve consequential actions.

Manufacturing integration analysis

Research mapped the publicly documented Tharstern MIS, Heidelberg Prinect and Speedmaster CD 102, HP Indigo systems, Enfocus Switch/PitStop and Aleyant Pressero. JDF/XJDF/JMF exchange and internal network topology were treated as possible integration patterns requiring on-site confirmation.

Proposed task-specific agents

Bounded automation with a human gate.

Prepress preflight

Read authorized file and PitStop/Switch reports, flag exceptions and prepare drafts. The operator approves releases.

JDF/MIS monitoring

Read approved ticket/status events and propose corrections. The supervisor approves changes.

IT troubleshooting copilot

Analyze selected logs, alerts and runbooks. The administrator executes all changes.

Documentation agent

Draft versioned runbooks from reviewed resolutions. A team lead approves publication.

Proposed delivery

Baseline before automation.

  1. Phase 0: Verify IT/OT boundaries, infrastructure, job flows, security, backups and operational metrics.
  2. Phase 1: Establish private inference, gateway policies and observable, read-first pilot infrastructure.
  3. Phase 2: Validate bounded agent pilots against real baselines and explicit acceptance tests.
  4. Phase 3: Extend approved agents and integration coverage after pilot results and human review.
  5. Phase 4: Institutionalize model evaluation, training, calibration, documentation and recovery.
