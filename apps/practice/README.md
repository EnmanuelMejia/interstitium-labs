# Practice app

Self-paced courses before they are folded into the public `docs/` site.

Math starts with an eight-item adaptive baseline. The bench is our editor: a SQL `readings` table and a Java buffer with no JVM. Manuals point at Vim, Emacs, VS Code, JetBrains, Eclipse, the JDK builds, PostgreSQL, Wolfram, and the ledgers. Roads follow a path, module, unit, and check for Microsoft, AWS, Google Cloud, Oracle, Vertica, Wolfram, CompTIA, Linux, HashiCorp, Kubernetes, diffusion, RAG, and chain development. Vendor exams are not stored.

No deadlines. Muse is a tutor at a desk. The motif stage is the mark.

This tree is the source of that practice. It is not served at interstitiumlabs.dev yet. `docs/` stays the live static site. The ThinkStation hypervisor comes later.

The runnable preview uses the app-builder shell (TanStack Start, Vite). Do not expect `npm install` in this folder alone to replace that shell.
