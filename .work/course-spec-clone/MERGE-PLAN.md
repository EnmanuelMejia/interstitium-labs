# Merge Plan — Complementary Programs + Frontier Topics

## Principle
Keep all 29 course codes/URLs stable. "Merge" = consolidate duplicative content,
fold frontier topics into the courses where they belong, and add heavy
cross-linking between complementary courses. Do NOT delete or renumber courses.
