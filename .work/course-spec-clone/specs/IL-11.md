## Learning Outcomes (objectives)
1. Explain the Zero Trust doctrine — never trust, always verify — and why the perimeter model failed.
2. Map attack classes to OSI and TCP/IP layers; apply hashing and encryption controls correctly.
3. Describe Active Directory structure and how attackers abuse Kerberos, hashes, and replication.
4. Design application allowlisting and ringfencing policies that contain threats without breaking the business.
5. Analyze phishing, web-application, and session attacks from red-team and blue-team perspectives.
6. Run detection and response: triage alerts, contain incidents, close the post-incident learning loop.
7. Administer Entra ID identity lifecycle, Conditional Access, authentication, hybrid identity, and governance.
8. Troubleshoot identity and endpoint issues with PowerShell and KQL.
9. Apply number theory and logic to crypto and policy reasoning (embedded math primers).
10. Prepare independently for CompTIA Security+ SY0-701 and CySA+ CS0-003, plus Microsoft SC-300/SC-100 readiness.
