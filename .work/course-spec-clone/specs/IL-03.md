## Learning Outcomes (objectives) — 6, preserved from existing content
1. Write idiomatic Python, Java, and C++ — and explain the same idea in all three.
2. Implement the core data structures and analyze the core algorithms from first principles.
3. Reason about computer organization, operating systems, networks, and databases as a system.
4. Work the MIT 6-3 reference layer: Python, discrete math, algorithms, computation structure.
5. Design and document APIs; build, test, and deploy a full-stack capstone.
6. Produce generative art from first principles: sampling, spatial grids, and parameters as art.
