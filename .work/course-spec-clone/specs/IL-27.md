## Learning Outcomes (objectives)
1. Administer Windows 10/11 and Windows Server (AD DS, GPO, DNS/DHCP, file/print) to a production standard.
2. Apply TCP/IP, subnetting math (CIDR/VLSM/supernetting), and network troubleshooting with Wireshark-level rigor.
3. Deploy and manage virtualization (Hyper-V, VMware concepts) and core Azure/AWS infrastructure services.
4. Run endpoint lifecycles: imaging/deployment, patch rings, Intune MDM, CIS-concept hardening, and application allowlisting.
5. Design and articulate Zero Trust architecture per NIST SP 800-207 and the CISA maturity model.
6. Execute the infrastructure side of incident response, backup/DR, logging/SIEM, and vulnerability management.
7. Operate monitoring, high availability, and capacity planning for reliable services.
8. Use foundational math (binary, Boolean logic, modular arithmetic, sets, probability, queuing, Big-O) in daily infrastructure work.
9. Build, document, and present a homelab capstone with a professional documentation portfolio.
10. Interview at a specialist level: STAR stories, live troubleshooting narration, and honest certification planning.
