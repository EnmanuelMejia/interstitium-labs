## Learning Outcomes (objectives)
1. Run the applied ML loop end to end: frame, baseline, evaluate, iterate, ship.
2. Engineer features without leakage and audit data pipelines for target contamination.
3. Choose evaluation metrics that match business cost and read confusion matrices honestly.
4. Build ensembles, calibrated probabilistic models, and practical deep architectures for tabular data.
5. Work with transformers at practitioner depth: attention, fine-tuning with LoRA, alignment tradeoffs, and GenAI evaluation.
6. Ship LLM features: APIs, RAG, tool use, eval harnesses, guardrails, and cost control.
7. Scope, prototype, and defend applied AI work to stakeholders with measured value.
8. Use the prereq math spine (statistics, linear algebra, discrete math) to reason about models, losses, and evaluation.
