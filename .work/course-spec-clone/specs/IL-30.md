You will learn the quantum threat model (Shor vs RSA/ECC, Grover vs symmetric, harvest-now-decrypt-later), the lattice math that carries modern cryptography (LWE, Module-LWE, NTRU-style problems), each standardized algorithm at implementation depth — key sizes, parameter sets, failure modes — hybrid key exchange in TLS 1.3, and the full migration discipline: crypto inventory, prioritization, protocol playbooks (TLS, SSH, VPN, code signing), and CNSA 2.0/NSM-10 compliance timelines. Hands-on labs take you from a toy lattice cipher in Python through liboqs to a hybrid TLS handshake you capture and inspect. No vendor certificate exists for PQC yet — the course aligns to the published NIST FIPS as independent study, not certification prep.

## Learning Outcomes (objectives)
1. Explain precisely which classical primitives fall to which quantum algorithm: Shor breaks RSA/DH/ECDSA/ECDH, Grover halves symmetric key strength, and why harvest-now-decrypt-later forces action before any quantum computer exists.
2. Work the lattice mathematics behind Module-LWE/Module-SIS: lattices, shortest/closest vector problems, modular arithmetic, and error distributions — far enough to read the algorithm specs.
3. Trace the NIST PQC competition from the 2016 call to the August 2024 finals and know exactly where every algorithm stands: final (FIPS 203/204/205), in standardization (HQC, FN-DSA), or still under evaluation.
4. Deploy ML-KEM (Kyber) correctly: parameter sets ML-KEM-512/768/1024, key/ciphertext sizes, the encapsulation protocol, and why misusing an ephemeral keypair breaks its security story.
5. Deploy ML-DSA (Dilithium) and SLH-DSA (SPHINCS+): parameter sets, signature sizes, Fiat–Shamir with aborts, hypertree-plus-FORS construction, and the size/performance tradeoffs that decide which signature to use where.
6. Design hybrid key exchange (X25519 + ML-KEM in TLS 1.3) and state the hybrid security property: the exchange is safe if EITHER component holds.
7. Build a crypto inventory and migration plan: discovery methods, CBOM practice, prioritization by exposure and data lifetime, and hybrid-first deployment strategy.
8. Execute protocol migration playbooks for TLS 1.3, SSH, IPsec VPN, and code signing — including the failure modes, rollback plans, and testing each step requires.
9. Run the toolchain: implement a toy lattice KEM in Python, drive liboqs, and stand up a hybrid TLS handshake with OQS-enabled software.
10. Read the policy landscape: CNSA 2.0 enforcement timeline, NSM-10, NIST IR 8547 transition guidance, and how federal mandates become organizational deadlines — without claiming any certification that does not exist.
