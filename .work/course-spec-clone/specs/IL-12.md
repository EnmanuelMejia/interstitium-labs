## Learning Outcomes (objectives)
1. Write the Python AI engineers actually use: syntax, objects/modules, environments, concurrency.
2. Wrangle data with NumPy, pandas, SQL, and honest statistics — preventing leakage from day one.
3. Train and evaluate classical ML models with rigorous validation and cost-matched metrics.
4. Build neural networks in PyTorch: gradients, optimization, regularization, hand-written training loops.
5. Work with transformers, diffusion, and LLMs: prompting, RAG, vector search, parameter-efficient fine-tuning.
6. Engineer NLP and agentic systems: tokenization, tool use, MCP, context engineering.
7. Ship production AI: serving patterns, monitoring/drift response, cost control, red-teaming.
8. Complete a deployed capstone: evaluation, model card, responsible-AI review.
9. Apply linear algebra, probability, and discrete math to ML (embedded math primers).
10. Prepare independently for AWS MLA-C01, Databricks Data Engineer Associate, and the TensorFlow Developer Certificate.
