## Learning Outcomes (objectives)
1. Master the math foundations data analysts actually use — arithmetic, algebra, functions, logarithms, summation, sets and logic, descriptive statistics, probability, linear algebra, and calculus concepts — with worked examples and drills, each module marked with the downstream modules it unlocks.
2. Write senior-level SQL fluently: window functions, recursive CTEs, query optimization, and execution-plan reading on realistic schemas.
3. Apply statistics correctly in analysis work: distributions, confidence intervals, regression, hypothesis testing, and A/B test design with sample-size reasoning.
4. Design dimensional models and reliable ETL/ELT pipelines with dbt-style transformations, orchestration concepts, and data-quality checks.
5. Map the exam domains, formats, and study plans of seven data-analytics certifications (Google, PL-300, Tableau, CompTIA Data+, IBM, AWS, Databricks) via the Certification Crosswalk and build a personal certification roadmap.
6. Meet the senior hiring bar at Palantir-style and BNY Mellon-style organizations: interview-grade SQL under pressure, probability brainteasers, product-sense cases, ontology thinking, the banking data domain (trades, P&L, VaR concepts, reconciliation), financial reporting controls, and production analyst ownership.
7. Build decision-grade dashboards and analyses in BI tools and Python, communicating findings to stakeholders with clarity and influence.
8. Ship an undeniable 7-project portfolio — GitHub repos, dashboards, and a capstone — and perform in senior analyst interview loops (SQL live-coding, cases, take-homes).
