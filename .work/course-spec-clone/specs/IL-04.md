## Learning Outcomes (objectives) — 5, preserved from existing content
1. Administer Linux from first principles: filesystem, permissions, shell, systemd, storage, networking, SELinux.
2. Automate with bash and Ansible: idempotent playbooks, roles, and scheduled execution.
3. Administer Windows Server: NTFS, Active Directory, Group Policy, PowerShell, DNS/DHCP.
4. Troubleshoot networks by layer with packet-level evidence: addressing, switching, routing, DNS.
5. Pass performance exams (EX200/EX294) via timed hands-on scenarios — not multiple-choice cramming.
