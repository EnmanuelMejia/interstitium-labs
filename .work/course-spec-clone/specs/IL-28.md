## Learning Outcomes (objectives)
1. Master the infrastructure math: binary/hex, Boolean logic, subnetting/CIDR, set theory, modular arithmetic, and reliability statistics — with worked examples for every concept.
2. Troubleshoot Linux/RHEL like a panel expects: inodes, file descriptors, ports, systemd, SELinux, and full connectivity runbooks.
3. Explain and build cloud networking: TCP/UDP, DNS, VNet/VPC, Private Link/Private DNS, and L4 vs L7 load balancing with real traffic flows.
4. Ship containers and orchestration: Docker layers and multi-stage builds, Kubernetes triage (Pending, CrashLoopBackOff, OOMKilled/exit 137), probes, scheduling, and Helm.
5. Run infrastructure as code: Terraform (state, drift, import, for_each, modules, secrets) and Ansible (playbooks, roles), and argue the Terraform-vs-Ansible trade-offs cold.
6. Build CI/CD: pipeline phases and quality gates, Jenkins with Groovy shared libraries, and modern GitHub Actions/Azure DevOps pipelines.
7. Operate Azure, AWS, and GCP: storage, Key Vault, AKS node pools and autoscaling, VPC, IAM, and multicloud strategy.
8. Observe and secure production: Prometheus/Grafana/ELK, SLOs and incident response, SAST/DAST, secrets management, supply-chain security, and RBAC.
9. Answer every real BNY DevOps panel question independently — no copilot — in a timed 90-minute mock panel.
