2. Analyze algorithms: asymptotics, divide-and-conquer, dynamic programming, graphs, NP-completeness.
3. Build systems: from gates to processors, C to kernels, single-node to distributed.
4. Reason about concurrency, databases, and operating systems at the implementation level.
5. Read MIT 6-3, CMU, and Stanford curricula with load-bearing-idea discipline.
6. Translate proofs into code and measurements (every algorithm proven is implemented and timed).
