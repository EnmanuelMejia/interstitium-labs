## Learning Outcomes (objectives)
1. Model and query document databases: aggregation pipelines, embedding-vs-referencing, indexing (MongoDB).
2. Build data pipelines: ingestion, orchestration, warehousing, quality, and governance.
3. Apply probability and linear algebra to analytics and ML tasks (embedded math primers).
4. Train and evaluate ML models: supervised learning through reinforcement learning first contact.
5. Engineer LLM systems: RAG, vector databases, fine-tuning (LoRA/QLoRA), evaluation, agents, MLOps.
6. Self-host open-weight models: quantization, Ollama/llama.cpp/vLLM, licensing literacy.
7. Build agents: the ReAct loop, LangGraph-style state machines, MCP tools, evaluation.
8. Track frontier AI topics and cite the survey source (IL-23) for further reading.
9. Prepare independently for AWS DEA-C01/MLA-C01, Databricks Data Engineer Associate, CompTIA Data+, and dbt Analytics Engineering.
10. Operate on AWS data and ML services through vendor-neutral engineering patterns.

## Noah Tutoring — the core learning driver

Noah is the tutoring driver for the data-to-model journey: it teaches the math, pairs on the pipelines, and stress-tests your ML reasoning — by voice, adaptively, and always grounded in this course's modules.

**Personas → modules:**

- **The Visionary** (visionary): Paints the end-state: where the data platform and the AI system are going, and why this module matters on that arc.
  - Modules: il07-ai-ml, il07-openweight, il07-agents, il07-frontier, il07-aws-ml
- **The Engineer** (engineer): Pairs with you on labs: pipelines, dbt models, aggregation queries, and cloud builds — reviews your code and finds the bug.
  - Modules: il07-mongodb, il07-data-schools, il07-aws-data, il07-aws-ml
- **The Philosopher** (philosopher): Goes deep on the why: the math behind the model, what a probability statement means, how brains inspired the architectures.
  - Modules: il-07-data-engineering-analytics-ai-math-stats, il-07-data-engineering-analytics-ai-math-linalg, il07-neuroai, il07-frontier
- **The Mentor** (mentor): Runs review and readiness: Socratic check-ins, gate prep, study scheduling, and honest feedback on weak spots.
  - Modules: il07-data-schools, il07-ai-ml
- **The Trickster** (trickster): Plants the traps so the exam can't: leaky features, silent data-quality failures, quiz distractors that punish shallow reading.
  - Modules: il07-mongodb, il07-data-schools, il07-ai-ml

**Voices:** Five natural voices — one distinct voice per persona, switchable at any time. Voice chat runs alongside the module so learners can talk with Noah mid-lab without breaking flow.

**Voice-first:** Learners talk with Noah via voice chat while working through modules — ask mid-lab, get answers without breaking flow.

**Adaptive (SM-2 spaced repetition):** SM-2 spaced repetition drives Noah's memory of the learner: every flashcard, quiz answer, and drill result feeds an SM-2 scheduler that re-surfaces weak items at the optimal interval. Noah adapts explanations to the learner's level and re-routes the study plan toward the weakest published exam domains or skill gaps.

**Course-aware:** Noah is course-aware: it knows this course's modules, the learner's progress, the certification gates, and the cross-linked companion courses. It answers from the course's own material first, cites module IDs, and routes deeper questions to the right module or companion course.

**Bleeding edge:** The frontier AI module (il07-frontier) is fed by the daily-fold trend pipeline: Noah surfaces fresh model releases, licensing changes, and architecture shifts as they happen, and ties them back to the module's concepts.

**Rule:** Noah teaches from this course's material and its cross-linked companions; it never invents credentials, exam content, or vendor claims.
