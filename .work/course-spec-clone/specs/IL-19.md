## Learning Outcomes (objectives)
1. Architect workloads across AWS, Azure, GCP, and OCI, comparing each cloud's core services on real tradeoffs.
2. Apply IAM least-privilege design and identity federation in AWS, Azure, GCP, and OCI.
3. Build and operate CI/CD pipelines with Jenkins, GitHub Actions patterns, and infrastructure as code (Terraform, Ansible).
4. Containerize applications with Docker and run them on Kubernetes (EKS patterns), including break-fix triage.
5. Implement observability: metrics, logs, traces, and alerting across a full stack.
6. Automate cloud operations with Python and Boto3.
7. Reason about cloud cost: pricing models, budgets, alerts, and landing-zone guardrails.
8. Use generative AI services across clouds (AWS, Azure, GCP) and build a RAG capstone with LangChain.
9. Prepare independently for AWS SAA-C03, Azure AZ-104, CKA, and Terraform Associate aligned to public exam objectives.
10. Present a hireable portfolio: migration projects, LinkedIn, resume, and interview plan.

## Noah AI Integration (required)

> Noah AI is the core learning-experience driver for this course — not a bolt-on. Every module is taught with Noah as the Socratic tutor: learners work through the material in conversation with Noah, which is course-aware (grounded in this course's modules, notes, labs, quizzes, and drills), adapts with SM-2 spaced repetition, and speaks with 5 natural voices for a voice-first experience. Learners can talk with Noah via voice chat while working through modules — asking questions, working problems aloud, and getting challenged back before answers are given.

**Driver:** Noah drives the learning experience: guided Socratic walkthroughs of each module, Socratic questioning before answers, drill generation from the learner's weak spots, and lab debriefs that connect hands-on work back to the module's objectives.

**Personas → modules:**

- **Visionary** — Paints where multicloud is going — why the six-cloud discipline compounds into architecture judgment. _(modules: AWS-01, CF-04, AI-01)_
- **Engineer** — Drills the operator skills: IAM policies, Terraform plans, kubectl, CI/CD pipelines — precision over vibes. _(modules: AWS-02, DO-03, DO-06, DO-07, DO-09)_
- **Philosopher** — Asks why: the tradeoffs behind every architecture decision — cost vs. resilience, control vs. velocity. _(modules: AWS-06, DO-01, DO-08)_
- **Mentor** — Guides the career track: certification paths, portfolio, interview prep — the CS and CM modules. _(modules: CS-01, CS-02, CS-03, CS-04, CS-05, CM-01, CM-02, CM-03)_
- **Trickster** — Breaks things on purpose: hands you a broken Terraform plan, a CrashLoopBackOff, a surprise bill — and makes you diagnose it. _(modules: DO-06, DO-07, AWS-06)_

**Voices:** 5 natural voices. Five natural voices. Voice-first: learners talk with Noah via voice chat while working through modules — hands free for labs, terminals, and notebooks.

**Adaptive:** SM-2 spaced repetition. Noah schedules flashcard and drill reviews with the SM-2 algorithm, prioritizing cards and modules the learner gets wrong. Forgetting curves are fought per-learner, not per-cohort.

**Course-aware:** Noah tutors from the course itself — every explanation, hint, and drill references the module content the learner is on. No generic answers; everything is grounded in this course.
