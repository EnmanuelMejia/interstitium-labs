## Learning Outcomes (objectives)
1. Build agent loops from the primitives: tool contracts, perceive-reason-act, memory, and stopping conditions.
2. Design multi-agent systems only when one agent is provably insufficient — and coordinate them without collapse.
3. Evaluate agents on trajectory quality, tool efficiency, and safety adherence — not just task success.
4. Apply agents across software, data, product, and program workflows with least-privilege tooling.
5. Ship low-code agents with scoped connectors, monitoring, and a clear graduation path to pro-code.
6. Design agentic systems on a whiteboard and defend the tradeoffs in interviews.
7. Use the prereq math spine (logic, probability, discrete math) to reason about agent search, planning, and evaluation statistics.
