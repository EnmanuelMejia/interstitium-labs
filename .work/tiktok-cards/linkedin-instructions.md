## How to Update LinkedIn Featured Section

1. Go to your LinkedIn profile: https://linkedin.com/in/enmanuelmejia
2. Scroll to the **Featured** section
3. Click the **+** (plus) icon → **Add a post** or **Add media**
4. For each project:
   - Upload the corresponding 1200×627 PNG
   - Add title (e.g., "IL-29 · ThreatLocker Zero-Trust CBT with AI")
   - Add link to the project page
   - Add description

### Or Update Existing Featured Items:
1. Click the pencil icon on an existing featured item
2. Replace the thumbnail with the new cinematic card PNG
3. Save
